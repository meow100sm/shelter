# Технологический стек проекта PawCare (Shelter project)

Дата: 2026-05-25.

Ниже перечислены технологии и зависимости, которые **фактически используются в проекте** (по конфигурации и исходникам), а также dev-инструменты, которые поставляются как опциональные.

---

## 1) Язык и рантайм

- **Python**: проект рассчитан на Python 3.10–3.12 (в Docker используется Python **3.12-slim**).
- **WSGI/ASGI**: присутствуют стандартные точки входа Django (`shelter/wsgi.py`, `shelter/asgi.py`).

---

## 2) Backend (веб-приложение)

- **Django 4.2.15** — основной веб-фреймворк (MVC/MTV, маршрутизация, ORM, шаблоны, формы, админка).
- Приложения (Django apps) в составе проекта:
  - `accounts` — пользователи, роли, аудит, 2FA.
  - `animals` — карточки животных, ветеринарные записи, движения, фото.
  - `reports` — генерация отчётов.

---

## 3) База данных и доступ к данным

- **PostgreSQL** — основная БД для прод/демо.
  - В Docker Compose используется образ **postgres:16-alpine**.
- **psycopg2-binary 2.9.9** — драйвер PostgreSQL для Django.
- **SQLite (in-memory)** — используется *по умолчанию в автотестах*, чтобы тесты запускались без PostgreSQL.

---

## 4) Аутентификация, роли, безопасность

- Встроенная **Django authentication** (логин/логаут, смена пароля).
- **Ролевая модель доступа** реализована на уровне приложения `accounts` (role-based ограничения в views/permissions).
- **Двухфакторная аутентификация (TOTP)**:
  - **django-otp 1.5.0** + плагины `otp_totp` и `otp_static`.
  - **qrcode 7.4.2** — генерация QR-кода для настройки TOTP (выдаётся в шаблон как base64 PNG).
- **bcrypt 4.1.2** — зависимость присутствует в `requirements.txt`; прямого использования в коде не найдено (возможно оставлено «на будущее» или как альтернативный хэшер).

---

## 5) Работа с файлами и изображениями

- **MEDIA**: загрузка фотографий животных через `ImageField`.
- **Pillow 10.3.0** — обработка изображений (используется, например, при подготовке изображений в отчётах).

---

## 6) Отчёты и экспорт

- **PDF**: **ReportLab 4.1.0** — генерация PDF-отчётов (таблицы, стили, шрифты; поддержка русского текста через DejaVuSans при наличии шрифта в `static/fonts`).
- **Excel/XLSX**: **openpyxl 3.1.2** — генерация отчётов в формате Excel.
- **CSV**: экспорт журнала аудита через стандартный модуль Python `csv`.

---

## 7) Формы и фильтрация

- **django-filter 24.2** — фильтрация списков в представлениях.
- **django-crispy-forms 2.1** + **crispy-bootstrap5 0.7** — удобный рендеринг форм (template pack bootstrap5).

---

## 8) Frontend (UI)

- **Server-side rendering**: HTML-шаблоны **Django Templates** (`templates/`).
- **CSS**: кастомные стили в `static/css/style.css`.
- **JS**: минимальный vanilla JavaScript в `static/js/script.js` (например, поведение бокового меню на мобильных).
- **Шрифты**:
  - Roboto подключается через Google Fonts (в базовом шаблоне).
  - DejaVuSans используется для PDF (при наличии `static/fonts/DejaVuSans.ttf`).

---

## 9) Инфраструктура и запуск

- **Docker**:
  - `Dockerfile` собирает контейнер веб-приложения.
  - `docker-compose.yml` поднимает два сервиса: `web` (Django) и `db` (PostgreSQL) + volume для данных.
- Скрипты автоматизации:
  - PowerShell: `scripts/demo.ps1`, `scripts/backup.ps1`.
  - Bash: `scripts/demo.sh`, `scripts/backup.sh`.

---

## 10) Тестирование и качество кода (dev)

Dev-зависимости (опционально, из `requirements-dev.txt`):

- **pytest 8.3.3** — тестовый фреймворк.
- **pytest-django 4.9.0** — интеграция pytest с Django.
- **playwright 1.48.0** — e2e/браузерные тесты (используется Chromium в headless режиме).
- **ruff 0.6.9** — линтер/форматер.
- **vulture 2.11** — поиск неиспользуемого кода.
